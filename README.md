# 🩸 Early Screening of Chronic Myeloid Leukemia (CML) Using Machine Learning

## 📌 Project Overview

This project presents a machine learning–based web application for the early screening of **Chronic Myeloid Leukemia (CML)** using **Complete Blood Count (CBC)** parameters. A Random Forest classifier is trained on a synthetic medical dataset and deployed through **Streamlit** to provide instant predictions based on user-entered blood test values.

> **Disclaimer:** This application is developed for educational and research purposes only. It is **not** intended to replace professional medical diagnosis or clinical decision-making.

---

# 🚀 Features

* Predicts possible blood disorders from CBC parameters
* Interactive Streamlit web application
* Random Forest machine learning model
* Displays prediction confidence
* Shows probability for each disease class
* User-friendly interface
* Ready for deployment on Streamlit Cloud

---

# 🧬 Disease Classes

The model classifies the following conditions:

* Healthy
* Chronic Myeloid Leukemia (CML)
* Iron Deficiency Anemia
* Bacterial Infection
* Viral Infection
* Reactive Thrombocytosis

---

# 📊 Input Features

The model uses the following clinical parameters:

| Feature     | Description                               |
| ----------- | ----------------------------------------- |
| Age         | Patient age                               |
| Gender      | Male / Female                             |
| Severity    | Synthetic severity score (0–1)            |
| WBC         | White Blood Cell Count                    |
| RBC         | Red Blood Cell Count                      |
| Hemoglobin  | Hemoglobin Level                          |
| Hematocrit  | Hematocrit (%)                            |
| Platelets   | Platelet Count                            |
| MCV         | Mean Corpuscular Volume                   |
| MCH         | Mean Corpuscular Hemoglobin               |
| MCHC        | Mean Corpuscular Hemoglobin Concentration |
| RDW         | Red Cell Distribution Width               |
| Neutrophils | Neutrophil Percentage                     |
| Lymphocytes | Lymphocyte Percentage                     |
| Monocytes   | Monocyte Percentage                       |
| Eosinophils | Eosinophil Percentage                     |
| Basophils   | Basophil Percentage                       |

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/CML_ML_Project.git
```

Move into the project folder:

```bash
cd CML_ML_Project
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```

# 📈 Machine Learning Workflow

1. Generate synthetic patient records
2. Simulate realistic CBC laboratory values
3. Apply disease-specific modifications
4. Perform Exploratory Data Analysis (EDA)
5. Preprocess the dataset
6. Train a Random Forest classifier
7. Evaluate model performance
8. Save trained model using Joblib
9. Deploy with Streamlit Cloud
